# Security Controls

### Technical controls
- Controls implemented using systems
- Firewalls, Anti-virus

### Managerial controls
- Administrative controls associated with security design and implementation
- Security policies and standard operating procedures

### Operational controls
- Controls implemented by people instead of system
- Security guards

### Physical controls
- Lmits physical access
- Guard shack
- Fences, lock
- Badge readers

---

### Preventative control types
- Blocks access to a resource
- You shall not pass

### Deterrent control types
- Discourage an intrusion attempt
- Application splash screens
- Front reception

### Detective control types
- Identify and log an intrusion attempt
- May not prevent access
- Collect and review system logs
- Regular patrols

### Corrective control types
- Apply  a control after an event has been detected
- Reverse the impact of an event
- Restoring a backup can mitigate a ransomware infection
- Use a fire extinguisher

### Compensating control types
- Control using other means
- Existing controls are not sufficient
- May be temporary
- Prevent the exploitation of a weakness
